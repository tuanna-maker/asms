§01 Chuẩn bị

1. ASMS là gì? Cần chuẩn bị gì?

ASMS là phần mềm quản lý hậu mãi chạy trên máy chủ nội bộ của Viện (VTX). Nhân viên chỉ cần mở trình duyệt web (Chrome, Edge) để sử dụng — không cài app trên từng máy tính.

1.1 Máy chủ cần có (tối thiểu)

Hạng mụcYêu cầuGiải thích đơn giản
CPU4 nhân trở lênMáy chủ ảo hoặc vật lý trong mạng nội bộ
RAM8 GB (nên 16 GB)Càng nhiều người dùng càng cần RAM lớn
Ổ cứng80 GB SSD trở lênLưu phần mềm + file tài liệu upload
Hệ điều hànhWindows Server hoặc UbuntuUbuntu 22.04 khuyến nghị cho server
MạngLAN / VPN nội bộNhân viên truy cập qua địa chỉ nội bộ (ví dụ https://asms.vtx.local)

1.2 Phần mềm cần cài trên máy chủ

  • Docker Desktop hoặc Docker Engine — “hộp đựng” chạy ASMS, không cần cài Node.js thủ công
  • PostgreSQL — cơ sở dữ liệu (có thể cài trên cùng máy hoặc máy DB riêng)
  • Trình duyệt trên máy bạn — để kiểm tra sau khi cài xong
Lưu ý: Bạn không cần biết lập trình. Chỉ cần làm theo từng bước, copy dán lệnh đúng như hướng dẫn. Nếu chưa quen Docker, nên nhờ Unicom hỗ trợ lần đầu (onsite hoặc TeamViewer).

§03 Bàn giao

3. Nhận bàn giao từ Unicom

Sau khi ký biên bản bàn giao, bạn sẽ nhận một trong hai cách:

Cách A — Nhận file nén / USB (khuyến nghị nếu không có Git)

  • asms-frontend-1.0.0.tar — gói giao diện web
  • asms-backend-1.0.0.tar — gói xử lý máy chủ
  • docker-compose.yml — “bản đồ” khởi chạy
  • .env.mau — mẫu cấu hình (đổi tên thành .env và điền thông tin thật)
  • Thư mục backend/uploads (tạo mới nếu chưa có)

Cách B — Clone mã nguồn (nếu VTX có Git)

Unicom cung cấp đường dẫn repo và tag phiên bản v1.0.0. Kỹ sư IT clone về thư mục C:\asms hoặc /opt/asms.

Ghi chú thư mục làm việc trong suốt tài liệu: C:\asms (Windows) hoặc /opt/asms (Linux). Mọi lệnh bên dưới chạy trong thư mục đó.

§04–05 Docker & file

4. Cài Docker (phần mềm chạy ASMS)

1

Tải Docker

Vào trang docker.com → tải Docker Desktop (Windows) hoặc cài Docker Engine (Ubuntu theo hướng dẫn IT).

2

Cài đặt và khởi động

Bấm Next → Finish. Mở Docker Desktop, đợi biểu tượng cá voi ở khay hệ thống hiện “Running” (màu xanh).

3

Kiểm tra đã cài thành công

Mở PowerShell (Windows) hoặc Terminal (Linux), gõ:

Lệnh kiểm tra
docker --version

Nếu hiện số phiên bản (ví dụ 24.x) → Docker đã sẵn sàng.

5. Đặt file lên máy chủ

  1. Tạo thư mục C:\asms (hoặc /opt/asms).
  2. Copy toàn bộ file bàn giao vào thư mục đó.
  3. Tạo thêm 2 thư mục con (nếu chưa có):
    backend\uploads\documents và backend\uploads\workflow
Nếu nhận file .tar: mở PowerShell trong thư mục C:\asms, chạy lần lượt:
docker load -i asms-frontend-1.0.0.tar
docker load -i asms-backend-1.0.0.tar

Chờ đến khi báo “Loaded image”. Đây là bước “nhập hộp” phần mềm vào Docker.

§06 Cấu hình

6. Điền file cấu hình (.env)

File .env giống “phiếu khai thông tin” cho máy chủ. Mở bằng Notepad (không dùng Word).

Dòng cần điềnÝ nghĩa (dễ hiểu)Ví dụ
FRONTEND_IMAGE Tên gói giao diện asms-frontend:1.0.0
BACKEND_IMAGE Tên gói xử lý asms-backend:1.0.0
FRONTEND_PORT Cổng web (thường để 80) 80
DATABASE_URL Địa chỉ + mật khẩu PostgreSQL Unicom / DBA cung cấp
JWT_SECRET Mã bí mật đăng nhập (chuỗi dài ngẫu nhiên) Nhờ IT sinh — không chia sẻ
NODE_ENV Môi trường chạy thật production
Không gửi file .env qua email công khai. Không đăng lên mạng. Lưu backup trong két mật khẩu nội bộ VTX.

6.1 Cơ sở dữ liệu PostgreSQL

Nếu chưa có DB, nhờ quản trị CSDL tạo:

  • Tên database: asms
  • Tài khoản riêng (ví dụ asms_app) + mật khẩu mạnh
  • Chỉ cho phép máy chủ ASMS kết nối (cổng 5432)

Unicom có thể hỗ trợ tạo DB lần đầu qua TeamViewer.

§07 Khởi chạy

7. Khởi chạy ASMS — 5 lệnh chính

Mở PowerShell / Terminal, cd vào thư mục asms, chạy lần lượt từ trên xuống. Chờ lệnh trước xong rồi mới chạy lệnh sau.

①

Bật hệ thống

docker compose up -d

Lần đầu có thể mất 1–2 phút. Khi xong, 2 “hộp” frontend + backend đang chạy ngầm.

②

Kiểm tra đang chạy

docker compose ps

Cột STATUS phải ghi running cho cả asms_frontend và asms_backend.

③

Tạo bảng dữ liệu (chỉ lần đầu)

docker compose exec backend npx prisma migrate deploy

Chờ đến khi không còn dòng lỗi màu đỏ.

④

Tạo tài khoản quản trị lần đầu

docker compose exec backend npm run bootstrap:auth

Tạo user mẫu. Đổi mật khẩu ngay sau khi đăng nhập lần đầu.

⑤

Xem nhật ký nếu có lỗi

docker compose logs -f backend

Bấm Ctrl+C để thoát. Chụp màn hình gửi Unicom nếu cần hỗ trợ.

Tắt / bật lại sau khi khởi động server:
Tắt: docker compose down · Bật lại: docker compose up -d

§08 Đăng nhập

8. Mở trình duyệt & đăng nhập

1

Mở địa chỉ web

Trên máy cùng mạng nội bộ, mở Chrome/Edge và gõ:

http://<địa-chỉ-máy-chủ>/login

Ví dụ: http://192.168.1.50/login hoặc https://asms.vtx.local/login (nếu IT đã cấu hình HTTPS).

2

Đăng nhập lần đầu

Dùng tài khoản do bước bootstrap tạo (Unicom cung cấp trong biên bản). Mật khẩu mặc định demo: Password123! — phải đổi ngay.

3

Kiểm tra nhanh

  • Vào được màn hình Dashboard (trang chủ)
  • Menu bên trái hiện đủ mục (Hợp đồng, Khách hàng…)
  • Đăng xuất và đăng nhập lại được

8.1 Sau khi cài xong — việc quản trị viên nên làm

  1. Đổi mật khẩu admin
  2. Vào Cài đặt → Người dùng tạo tài khoản thật cho từng phòng ban
  3. Vào Cài đặt → Hệ thống chỉnh SLA, nhắc lịch (nếu cần)
  4. Thống nhất lịch backup database với IT (hàng ngày)
Hướng dẫn sử dụng phần mềm (không phải cài đặt): xem docs/huong-dan-su-dung-asms.md.

§09–10 FAQ & liên hệ

9. Câu hỏi thường gặp

❓ Mở trình duyệt báo “Không truy cập được trang”
Kiểm tra: (1) Docker đang chạy? (2) Lệnh docker compose ps có 2 dòng running? (3) Máy bạn cùng mạng LAN với server? (4) Firewall có chặn cổng 80 không?
❓ Đăng nhập được nhưng màn hình trắng hoặc lỗi liên tục
Thường do cấu hình sai. Chạy docker compose logs backend, chụp màn hình gửi Unicom. Không tự sửa file trong thư mục phần mềm.
❓ Quên mật khẩu admin
Liên hệ Unicom hoặc IT có quyền server để reset qua lệnh bootstrap (cần truy cập máy chủ).
❓ Cần tắt máy server bảo trì
Chạy docker compose down trước khi tắt. Sau khi bật server lại: docker compose up -d. Dữ liệu vẫn giữ nếu không xóa thư mục uploads và DB.
❓ Cập nhật phiên bản mới
Unicom gửi file .tar phiên bản mới + hướng dẫn. Luôn backup database trước khi cập nhật. Chi tiết kỹ thuật: mục 17 trong ASMS_phuong-an-trien-khai.html.

10. Liên hệ hỗ trợ

Trong giờ triển khai
Đội kỹ thuật Unicom (số hotline / email trong hợp đồng bảo hành phần mềm)
Nội bộ VTX
Phòng CNTT / quản trị mạng — firewall, HTTPS, backup server
Khi gọi hỗ trợ, chuẩn bị sẵn: ảnh chụp docker compose ps, 10 dòng cuối của docker compose logs backend, và mô tả “đã làm đến bước mấy”.

Checklist hoàn tất cài đặt

  • Docker chạy · 2 container running
  • Migrate + bootstrap thành công
  • Đăng nhập web OK · đổi mật khẩu admin
  • Tạo user thật · backup DB lần đầu
  • Ký biên bản nghiệm thu cài đặt
